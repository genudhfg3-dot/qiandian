## 千点 v1.2.1 · 截图之后，随手问

新增常驻「随手问」助手，让截图、理解和收藏连在一起。

- **针对截图提问**：Snipaste 等工具截图复制后，一键翻译或提问，支持解释图片、提取文字和连续追问。
- **有用问答保存到知识库**：整理标题、正文与标签后保存，也可保留对话中的原始文字和截图。
- **一点即达**：原有爱心按钮直接快捷收藏，右上角星形角标直接问 AI，无需再次选择。
- **随时唤起**：默认 Alt+R，可在设置中自定义；也支持文字问答、选中文字答疑、置顶、停止与重试。

### 开始使用

下载下方 `千点-1.2.1-x64.exe` 安装。升级前请从系统托盘退出旧版，升级会保留本地数据与设置。

**请使用支持图片理解（视觉／多模态）的大模型，纯文字模型无法处理截图。** 每位用户需在 AI 设置中填写自己的模型和 API Key；AI 调用需要联网，费用与速度取决于服务商。
