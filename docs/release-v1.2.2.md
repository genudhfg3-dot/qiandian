## 千点 v1.2.2 · 问答窗口修复

修复连续问答后，输入栏下方出现大块空白、窗口出现双层滚动条的问题。长回答只在消息区滚动，输入栏保持在窗口底部，调整窗口大小和缩放后也能正常使用。

截图随手问、图片翻译、文字提取，以及将重要问答和截图保存到知识库等功能继续保留。

### 下载与升级

下载下方 `Qiandian-1.2.2-x64.exe` 安装。升级前请先将重要问答保存到知识库，再从系统托盘退出旧版。升级会保留已保存的本地数据与设置；未保存的助手对话退出后会清空。

**截图问答需要支持图片理解（视觉／多模态）的大模型。** 请在 AI 设置中填写自己的模型配置和 API Key。

安装包校验值见下方 `SHA256SUMS.txt`，完整更新记录见 [CHANGELOG](https://github.com/genudhfg3-dot/qiandian/blob/v1.2.2/CHANGELOG.md)。
