# Electron Dev 烟测清单

运行：

```powershell
npm run electron:dev
```

## 托盘打开知识库

1. 启动后确认悬浮爱心按钮出现。
2. 左键点击系统托盘图标。
3. 预期：打开的是“个人知识库”主窗口，不是快速笔记捕获窗。
4. 右键托盘图标，点击“快速笔记”。
5. 预期：打开快速笔记捕获窗。

## 悬浮按钮打开捕获窗

1. 点击悬浮爱心按钮。
2. 预期：打开快速笔记捕获窗，正文输入框自动聚焦。
3. 输入一段内容，等待约 1 秒。
4. 预期：底部状态变为“保存成功”。

## 原生关闭自动保存

1. 在快速笔记中输入一段新内容。
2. 点击窗口右上角系统关闭按钮。
3. 预期：窗口不会立刻消失，会短暂显示“已保存，正在关闭。”，随后关闭。
4. 打开知识库窗口。
5. 预期：刚才的内容出现在列表中，不需要重启应用。

## 预览与格式

1. 选中正文中的一段文字。
2. 分别点击加粗、变颜色、变字号、高亮按钮。
3. 点击工具条中的“预览”。
4. 预期：格式能在预览中可视化显示。

## 草稿恢复

1. 输入内容后立刻关闭/异常结束应用，或模拟保存失败后重新打开捕获窗。
2. 预期：捕获窗恢复草稿并显示“丢弃草稿”。
3. 点击“丢弃草稿”。
4. 预期：正文清空，下次打开不再恢复该草稿。
